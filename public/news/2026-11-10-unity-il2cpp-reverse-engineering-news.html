dev/6.1.11108: Avoid ld64 warnings about duplicate libraries

Clang already links libSystem into every binary, and libc and libm are aliases of it on macOS, so bn_rust_native_static_libs now leaves all three out of the libraries needed to link with a Rust crate. Setting CMP0156 to NEW lets CMake drop a static library that appears more than once on a link line created from target dependencies.

Dynamic Analysis Frida Tools Releases 2026-11-09

14.13.1: application: Wait for cancellation on stdin EOF

With stdin redirected from /dev/null, readline() returns "" right away, so await_enter() stopped the reactor before frida-pull and frida-push did their work, and await_ctrl_c() spun at 100% CPU. When stdin is not a terminal, EOF means no line will ever arrive, so block until cancelled. On a terminal an empty read is Ctrl-D, which still returns as before.
